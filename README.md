A one-line joke about the demo, written by a tiny Python program. The joke: flawless in every rehearsal, the agent meets its first real user live — who clicks the one button nobody had tested — and demoed the crash as a feature. Running the program writes the joke, exactly 155 characters and byte-identical on every run, to `entry.txt` in the output directory (`/output` by default, or `$MAKEFUN_OUTPUT_DIR`).

## Run it

```sh
python3 main.py
```
